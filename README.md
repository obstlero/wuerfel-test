# Living Valley – Würfel-Test

Online: https://obstlero.github.io/wuerfel-test/

## Lokal starten

Du brauchst Node.js (Version 24) auf deinem Rechner. Öffne ein Terminal in diesem Ordner und installiere einmalig alles Nötige mit `npm install`. Starte die Seite dann mit `npm run dev`. Öffne im Browser die Adresse, die im Terminal angezeigt wird (meist http://localhost:5173/wuerfel-test/). Den automatischen Test führst du mit `npm test` aus.
